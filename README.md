# FortyGuard Product Feedback

Tried all three products as a new user: the Dashboard (Chicago, Illinois),
the API and the MCP (Phoenix, Arizona). 


### Overall

- Each product works well on its own, but the three products do not work consistently together, which can be confusing.


### What I liked

- **Dashboard:** Easy to use. I can create a heatmap by following the tutorial, click on areas to see results and details, use actions to capture views or tiles, and switch between map and satellite views. 
- **API:** error messages are clear, and refused requests don't cost credits.
- **MCP:** it told me the cost before spending credits, and it gave the same result as the API.


### What was confusing

- **No list of covered areas:** The dashboard created a map of Chicago, but the API and MCP did not accept the same area.
- **API quick start:** The Manhattan example did not work with my API key.
- **Different units:** dashboard shows Fahrenheit, while the API and MCP use Celsius. The dashboard's Heat Index also has no unit.
- **Phoenix heatmap:** It showed the same temperature (40.87C) across the map, so there was not much useful information to explore.
- **Credits:** I could not find my remaining credits. I only found them through an MCP tool that was not listed in the documentation (the docs list 9 tools, but I found 11).
-**MCP setup:** The setup guide did not match my computer. The claude command did not work in my VS Code terminal, so I had to add the server through the chat window instead.


### What I would suggest

- Provide a list of supported areas and use one of them in the quick start example.
- Show the unit next to every temperature and use the same units across all three products.
- Show the remaining credits and plan in the dashboard.
- Add setup instructions for Windows and the VS Code extension.
