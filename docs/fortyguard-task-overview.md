# FortyGuard

## The three products tested
- **Dashboard:** a website with a map. Check `dashboard.md`.
- **API:** the same data, but asked for with API. Check `api.md`.
- **MCP:** a way for an AI assistant to ask FortyGuard for me. Check `mcp.md`.

## My account
- API key received: **Yes**
- Starting credits: **1,000,000**
- Plan: **premium** (I learned this through MCP)
- Dashboard US state I chose: **Illinois**
- Dashboard limits: **30 heatmaps and 30 routes per day**
- Time to first successful API call: 50.1 seconds (after 4 refused attempts).

## What cost credits
- One heatmap: **4,220**
- One FortyGuard `env_params` request: **2,110** credits on a basic or startup plan, or **2,900** on a premium or hackathon plan.
- A refused request: **0**

## What I spent
- 2 heatmaps + 1 conditions request = **11,340 credits**
- Left at the end: **988,660**
